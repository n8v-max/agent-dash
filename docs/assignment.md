## 🧩 Task

For an imaginary product that allows engineers to run agents in the cloud (e.g. [Claude Code on the Web](https://www.anthropic.com/news/claude-code-on-the-web)), **vibe-code the production implementation of a customer-facing organizational-level analytics dashboard** around their use of such agents.

You decide what metrics are important and should be shown in the dashboard. Mock any APIs or data you need as necessary in the vibe-coded solution.

  - Stub data/APIs
